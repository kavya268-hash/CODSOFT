# Machine Learning Mini Projects

This repository contains three machine learning projects developed using Python and Scikit-learn. These projects demonstrate data preprocessing, feature engineering, model training, evaluation, and prediction using real-world datasets.

## Projects Included

### 1. Movie Genre Classification
Predicts the genre of a movie based on its plot description using Natural Language Processing (NLP) and Machine Learning.

**Dataset**
- IMDb Movie Genre Dataset

**Technologies Used**
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK

**Algorithm**
- TF-IDF Vectorizer
- Multinomial Naive Bayes

**Features**
- Text preprocessing
- Genre prediction
- Model evaluation

---

### 2. Credit Card Fraud Detection
Detects fraudulent credit card transactions using supervised machine learning algorithms.

**Dataset**
- Credit Card Fraud Detection Dataset (Kaggle)

**Technologies Used**
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

**Algorithms**
- Logistic Regression
- Random Forest Classifier

**Features**
- Data preprocessing
- Fraud prediction
- Performance evaluation

---

### 3. Spam SMS Detection
Classifies SMS messages as Spam or Ham using Natural Language Processing.

**Dataset**
- SMS Spam Collection Dataset

**Technologies Used**
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn

**Algorithm**
- TF-IDF Vectorizer
- Multinomial Naive Bayes

**Features**
- Text preprocessing
- Spam detection
- Prediction of new messages

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Machine-Learning-Projects.git
```

Move into the project directory:

```bash
cd Machine-Learning-Projects
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Required Libraries

```text
pandas
```
